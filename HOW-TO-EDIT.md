# Your portfolio: how to edit and publish it

## Files
- index.html            - the whole website
- images/photo.jpg      - your profile photo (replace it with any square photo, same name)
- images/greenran.jpg   - the GreenRAN figure
- files/Tanvir_CV.pdf   - your one-page CV (the "Download CV" button opens this)
- files/Tanvir_CV.tex   - the CV source, so you can edit it later

## Put it online for free (GitHub Pages) - do this first
1. On GitHub, create a new public repository named exactly: siyam-05.github.io
2. Upload index.html, HOW-TO-EDIT.md and the images and files folders
   (Add file -> Upload files, then drag in everything from this zip).
3. Go to Settings -> Pages, set Source to "Deploy from a branch", branch "main", folder "/ (root)".
4. After a minute your site is live at https://siyam-05.github.io
   (Your CV already links to this address, so it starts working as soon as the site is live.)
5. Add that link to LinkedIn (About and Contact info), your GitHub profile and your email signature.

## Edit the website (5 minutes)
1. Open index.html in VS Code (or Notepad).
2. Find the part that starts with `EDIT YOUR PORTFOLIO HERE`.
3. To add a project, news item, certificate, honor or paper: copy an existing entry
   between { and }, paste it below, add a comma between entries, change the text.
4. Save, then double-click index.html to check it in your browser.
5. Upload the changed file to the same GitHub repository. The live site updates in a minute.

## Edit the CV
1. Go to overleaf.com (free), click New Project -> Upload Project, and upload files/Tanvir_CV.tex.
2. Change the text, click Recompile, then Download PDF.
3. Rename it Tanvir_CV.pdf, put it in the files folder, and upload it to GitHub.
4. Keep it to ONE page. When you add something new, remove or shorten something old.

## Keep it fresh
- Add a News line every time you finish something real (course, project, paper, talk).
- When you have a paper, add it under publications and the section appears automatically.
  Add it to the CV too, as a "Publications" section right after Education.
- Keep the website and CV saying the same thing (same dates, same numbers).
- Keep everything true and checkable. Professors click the links.
